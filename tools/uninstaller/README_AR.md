# برنامج إزالة تعريب KH2FM — مستقل وعام

شغّل **KH2FM-Arabic-Uninstaller.exe** على Windows 10 أو 11 بنظام 64 بت. لا يحتاج تثبيت البرنامج أو Python أو اتصال بالإنترنت. يجد تثبيت التعريب، ويفحص ملفاته، ويحفظ نسخة احتياطية قبل الإزالة.

## الاستخدام

1. أغلق اللعبة وOpenKH Mod Manager.
2. شغّل EXE ووافق على صلاحيات المسؤول.
3. اضغط **فحص التعريب**. يظهر رقم التعريب المكتشف. عند اختيار المجلد يدويًا، اختر `KH2FM-Arabic`، وليس مجلد اللعبة.
4. اضغط **إزالة التعريب وحفظ نسخة احتياطية**، ثم أكد العملية.
5. انتظر رسالة النجاح. تستطيع بعدها تشغيل اللعبة أو تثبيت تحديث التعريب.

## الإصدارات

- التعريب **1.0.1** و**1.0.2**: قائمتا الملفات والبصمات مدمجتان في البرنامج، ولا يحتاجان تغيير المثبت القديم.
- الإصدارات القادمة: يعمل نفس EXE إذا وفّر المثبت `kh2ar_install_manifest.json` وفق القاعدة الثابتة Schema 1. إصدار البرنامج `1.0.0` منفصل عن رقم إصدار التعريب.
- لا يحتاج اختلاف نصوص الترجمة أو إضافة موارد `.bar` و`.png` و`.dds` إلى إعادة بناء الأداة ما دام سجل المثبت مطابقًا لهذه القاعدة.
- إذا تغير نظام التثبيت أو صيغة السجل أو نطاق الموارد، تحتاج الأداة تحديثًا؛ لا يمكن ضمان توافق كل تغيّر مستقبلي.
- integration للمثبتات القادمة موجود على فرع `tools/standalone-uninstaller`، ويحتاج إدخاله في فرع بناء تلك الإصدارات. مسودة مثبت 1.0.2 الحالية بقيت كما هي.

## الاستعادة

النسخة الاحتياطية مستقلة عن اللعبة، وتوجد هنا:

```text
%LOCALAPPDATA%\KH2FM-Arabic-Recovery\التاريخ-رقم-العملية\
```

افتحها من زر **فتح النسخة الاحتياطية**. لإرجاع الحالة قبل الإزالة، اضغط **استعادة الحالة قبل الإزالة** واختر المجلد الذي يحتوي `recovery.json`. احفظ هذا المجلد إلى أن تتأكد من النتيجة. سجل الاستعادة يحفظ قائمة ملفات الإصدار نفسه، لذلك لا يحتاج كتالوجًا جديدًا في EXE.

يحافظ البرنامج على ملفات الحفظ وأرشيف اللعبة والملفات خارج قائمته، ويعيد نسخ `.kh2ar.bak` التي سجلها المثبت. يبقي محمل المودات إذا وجدت مودات أخرى أو اختلفت إعداداته أو ملفاته. عند اختلاف ملفات التعريب عن سجل التثبيت، يوقف الإزالة كلها ويحفظ تقرير الفحص هنا:

```text
%LOCALAPPDATA%\KH2FM-Arabic-Remover\scan-report.json
```

تبقى الوثائق وOpenKH الاختياري والمجلدات الفارغة. البرنامج يزيل التعريب وإدخاله من قائمة تطبيقات Windows؛ لا يجري حذفًا عامًا للمجلدات.

## البناء والتحقق

المصادر والاختبارات متاحة في `tools/uninstaller`. مسار GitHub Actions يبني EXE على Windows، ويختبر محرك الملفات وسجل البرامج والواجهة. نتائج التنفيذ في `CORE_TEST_REPORT.json` و`WINDOWS_TEST_REPORT.json` و`BUILD_REPORT.json` المرفقة بالإصدار. هذه الاختبارات تستخدم ملفات تجريبية؛ لا تثبت تجربة اللعبة أو جهازك الفعلي.

البرنامج غير موقّع بشهادة تجارية. اسم التحميل ثابت: `KH2FM-Arabic-Uninstaller.exe`، وبصمته في `SHA256SUMS.txt`. لا يرسل بياناتك ولا يجري تنزيلات أثناء الاستخدام.
