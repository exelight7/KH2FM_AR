# حذف التعريب — افتح واضغط

1. أغلق اللعبة.
2. شغّل **KH2FM-Arabic-Uninstaller.exe** ووافق على صلاحيات المسؤول.
3. اضغط **حذف التعريب**.

مسار اللعبة مكتوب مسبقًا:

```text
C:\Program Files (x86)\Steam\steamapps\common\KINGDOM HEARTS -HD 1.5+2.5 ReMIX-
```

إذا كانت اللعبة في مكان آخر، غيّر المسار أو اضغط `...` لاختيار مجلد اللعبة. البرنامج يكتشف تثبيت التعريب ويتحقق من الملفات ويحفظ نسخة احتياطية تلقائيًا. لا تحتاج اختيار مجلد التعريب أو الضغط على فحص أو تأكيد آخر.

بعد نجاح الحذف تظهر رسالة **تم حذف التعريب**. يظهر رابط **تراجع عن الحذف** إذا احتجت إعادة التعريب أثناء بقاء النافذة مفتوحة.

يدعم مثبتَي التعريب 1.0.1 و1.0.2 مباشرة، والإصدارات القادمة التي تلتزم بسجل الملفات الثابت Schema 1. إصدار البرنامج الجديد 1.0.1 مستقل عن رقم إصدار التعريب. يعمل على Windows 10/11 x64 دون تثبيت Python أو اتصال أثناء استخدامه.

البرنامج يحافظ على ملفات الحفظ وأرشيف اللعبة والملفات المختلفة، ويحفظ نسخة تلقائية في `%LOCALAPPDATA%\KH2FM-Arabic-Recovery`. إذا اختير مجلد لعبة أخرى أو لم يوجد سجل تثبيت مناسب، لا يحذف شيئًا. تبقى الوثائق وOpenKH الاختياري والمجلدات الفارغة؛ تُزال موارد التعريب وإدخال التعريب من تطبيقات Windows.

الإصدار الجديد **مسودة**. صاحب المشروع يحمّله من Releases بعد تسجيل الدخول وينشره بنفسه. الأداة السابقة أصبحت مسودة كذلك؛ مثبت التعريب 1.0.2 بقي مسودة دون تغيير.

التقرير الكامل ونتائج اختبارات Windows وصور الواجهة الفعلية ومصادر البناء مرفقة بالمسودة. اختبارات الحذف والتراجع تستخدم ملفات تجريبية، وليست تجربة اللعبة أو جهاز المستخدم. البرنامج غير موقّع بشهادة تجارية؛ بصمته مرفقة في SHA256SUMS.txt.
