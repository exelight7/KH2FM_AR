# جمع بيانات موضع الأوامر الخضراء

هذه أداة فحص مستقلة لـWindows x64. لا تثبت تعريبًا ولا تغيّر موضع الخط.

1. فك ضغط الحزمة، ثم افتح **KH2FM-HUD-Layout.exe**.
2. اختر مجلد اللعبة الذي يحتوي **KINGDOM HEARTS II FINAL MIX.exe**. من Steam: إدارة ← تصفّح الملفات المحلية.
3. احفظ **KH2FM-HUD-Layout.zip** على سطح المكتب، ثم أرفقه في المحادثة.

تقرأ الأداة حزم KH2 من مجلد Image وتستخرج ملفات تخطيط القوائم الـ27 الأصلية فقط، ومنها bb0command للقصر وhe0command للعالم السفلي وzz0command، المتاحة بلغة English. يلزم العثور على he0command حتى ينجح الفحص. يحتوي ملف ZIP الناتج على التخطيط وبصمات الملفات وأسماء الحزم، دون مسارات شخصية أو ملفات حفظ أو بيانات حساب. تُفتح ملفات اللعبة للقراءة فقط؛ احفظ ملف الفحص خارج مجلد اللعبة وباسم جديد.

يحتاج Windows إلى .NET Framework 4.x. الأداة مستقلة عن اللانشر ولا تغيّر قناة تحديثه.

يعتمد قارئ الحزم على صيغة HED/PKG وخوارزمية OpenKH؛ مرفق ترخيص Apache 2.0 ونسب المصدر. تُختبر القراءة باستخدام عينات OpenKH الاصطناعية، وحدود الملفات، وتطابق الملفات الأصلية قبل الجمع وبعده. لا تتضمن الحزمة أي ملفات من اللعبة.
