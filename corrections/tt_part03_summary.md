# Summary: tt_part03

- Rows reviewed: 250
- Rows corrected: 13

## Top repeated error patterns

1. Wrong word for the meaning: «لتدمرك» → «لأدمرك» (13571, the order is for
   Axel to destroy Roxas), «عم تتحدث» ("about what") → «لمن تتحدث» ("to whom")
   (13620), «سلطة سورا» ("authority") → «قوة سورا» (13605), «بعنف» → «بلهفة»
   (13582).
2. Spelling slips: «كتبتنا» → «كتبنا» (13494), «أكملين» → «كاملين» (13582), the
   garbled «يوجد ماكية» → «لا بد من حيلة» (13480), «عن من» → «عمن» (13515).
3. Gender: Naminé says «أنا آسف» → «أنا آسفة» (13536); «هذه مصير» → «هذا مصير»
   (13607).
4. Missing words: «يا لها من قصة حب» (13686), «أأنت بخير» (13703), «يا رفاق»
   (13544).
5. «بالملء» → «بالامتلاء» (13561).
