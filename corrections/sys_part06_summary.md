# Summary: sys_part06

- Rows reviewed: 250
- Rows corrected: 7

## Top repeated error patterns

1. Adjective attached to an indefinite noun as if it were an idafa: «خاتم
   الكوني», «حزام الكوني», «باندانا الإلهية» → «الخاتم الكوني», «الحزام
   الكوني», «الباندانا الإلهية» (14909, 14939, 14929).
2. Letter dropped from a spell name: «فاياغون» → «فايراغون» (14957; 14955
   «فاياغا» is the same error, see below).
3. Double article: «الالتزامن» → «التزامن» (14613).
4. Verbal noun written with alef maqsura: «تلقى الضرر» → «تلقي الضرر» (14918).
5. Two lines in reverse order, so the sentence started with its last words
   (14906).
