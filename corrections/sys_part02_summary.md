- Rows reviewed: 250

## Top repeated error patterns

1. Imperative written with an extra letter: «أنهي» for «أنه» (1217); the same
   pattern «اغادر» for «غادر» is in the glossary (see below).
2. Object noun without accusative ending: «اصنع ألعاب» → «اصنع ألعابا» (1257).
3. Preposition + first-person pronoun: «عنني» → «عني» (1337).
4. Demonstrative/number not agreeing with the noun: «بتلك الثلاثة المهرجين» →
   «بأولئك المهرجين الثلاثة» (1422).
5. Adjective needs a definite noun: «في شكل الأخير» → «في الشكل الأخير»
   (1122; allowed since «الشكل» became an unprotected term).
6. No other repeated pattern; most rows are menu labels, names and spell names
   that are correct as installed.
