# خط عربي بنسب طبيعية — مرشح 1.0.8

استبدال خط القوائم والحوار بـNoto Sans Arabic Regular، مع زيادة سماكة بمقدار ربع بكسل HD وحافة خفيفة. لا يمدد جسم الحرف أفقيا، ولا يفرض عليه عرض خلية الخط السابق. يشتق تقدم الحروف من قياس الخط وحدود الحبر، مع وصلات قصيرة عند حدود الخلايا.

- [مقارنة مختصرة قبل وبعد](comparison-summary.png).
- [مقارنة الحوار](comparison-dialogue.png): صفوف 1.0.7 ثم الخط الجديد، على خلفية صفراء وداكنة.
- [مقارنة القوائم](comparison-menu.png).
- هذه محاكاة لأطلس اللعبة، وليست لقطات داخل اللعبة.

الملفات الأربعة في `font-overlay.zip` مخصصة لدمجها مع بناء التعريب الكامل. تثبيت النسخة الكاملة عبر برنامج الإدارة يحفظ توافق بصمات الملفات وسجل التراجع. النسخ اليدوي فوق مود يديره البرنامج سيجعله يعتبر الملفات معدلة؛ لا تستخدمه بديلا عن التحديث الكامل إذا احتجت التحديث والحذف من البرنامج.

## التحقق

- 235 خلية عربية: خلفيات RGB صفرية عند انعدام alpha، وحافة الحوار منفصلة عن جسم الحرف.
- 1145 زوج اتصال في القوائم و1654 في الحوار: بلا انقطاع في HD وSD.
- 478 زوجا غير متصل في القوائم و752 في الحوار: بلا تلامس بين أجسام الحروف.
- 15537 نصا قابلا للترميز: 15528 أضيق و9 بلا تغيير، وصفر أعرض من 1.0.7 باستخدام النص نفسه والجدول الجديد. استثنيت 15 رسالة إنجليزية لا يرمزها مرمز العربية؛ خلايا الأرقام واللاتينية لم تتغير.
- الأرقام واللاتينية والرموز الأصلية وصورها وتقدمها مطابقة لـ1.0.7. الأيقونات وبقية مداخل BAR لم تتغير.
- لم يختبر المظهر داخل اللعبة بعد.

## إعادة البناء

```bash
python experiments/fonts/natural-proportions/sources/build_font.py
python experiments/fonts/natural-proportions/sources/build_font.py --verify
python build/tools/check_font_texture.py experiments/fonts/natural-proportions/font-overlay.zip
```

Python 3.12، Pillow 12.3.0، وNumPy. ملف الخط الأصلي مرفق في `fonts/` بترخيص SIL OFL 1.1؛ انظر `FONT_SOURCE_LICENSE.txt`. تعتمد الأداة أيضا تنسيقات اللعبة وفحوص الإصدار السابق في `../outline-baseline/`، وتتحقق من الحزمة المدخلة ببصمتها.
