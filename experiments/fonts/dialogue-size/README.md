# خط الحوار العربي أصغر بـ10%

**الإصدار:** `v1.0.7`، مبني على خط `v1.0.5` (`../alef-spacing/font-overlay.zip`) ثم إصلاحات 1.0.6 (`../outline-baseline/`).

- حروف الحوار العربية (أطلس evt) وتباعدها صارت 90% من حجمها في 1.0.6. التصغير حول بداية الخلية وخط الوصل، فبقي خط القاعدة في مكانه وبقيت الأرقام عليه.
- جسور الوصل أعيد رسمها على الصفوف نفسها بكامل القوة، ثم أضيفت الحلقة الداكنة وأعيد ترميز SD كما في 1.0.6.
- خط القوائم (sys) وحروف اللعبة الأصلية (الأرقام واللاتينية) لم يتغير حجمها.
- لم يصبح أي سطر أعرض: 12,504 سطرا من الحوار صارت أضيق، وسطران بلا تغيير.

| الفحص | النتيجة |
|---|---|
| وصلات مقطوعة (1,648 زوجا متصلا في الحوار) | 0 |
| حروف غير متصلة تتلامس أجسامها | 0 |
| أقصى بكسلات جسم تغطيها حلقة حرف مجاور في زوج واحد | 3 |
| الفرق بين أسفل الرقم 1 وخط الوصل العربي | 0 بكسل |

- [المقارنة: 1.0.6 و1.0.7](comparison-dialogue.png) — محاكاة لرسم الأطلس، وليست لقطة من اللعبة.
- التفاصيل في [report.json](report.json)، والبصمات في [SHA256SUMS.txt](SHA256SUMS.txt).

```bash
python experiments/fonts/dialogue-size/sources/scale_font.py            # يكتب الحزمة والتقرير والمقارنة هنا
python experiments/fonts/dialogue-size/sources/scale_font.py --verify   # يعيد البناء ويقارن البكسلات والبايتات
```
