# النسخة اليدوية 2.0.1

- نفس ناتج التعريب المنشور في 2.0.1، بما يشمل الخطوط وإصلاح نصوص الشريط الأخضر وتحسين أسماء المناطق.
- توزيع مستقل دون اللانشر، مع تجهيز محلي بواسطة فروق تعتمد على نسخة المستخدم.
- ملفات BAT للتثبيت والحذف والفحص والتراجع، ومحرك وسجل ملكية مطابقان للنسخة العادية.
- لا تُرفق ملفات PKG/HED أو أصول اللعبة الكاملة، ولا تتغير ملفات الإصدار العادي أو قناة تحديثه.
