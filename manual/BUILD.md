# بناء النسخة اليدوية

متطلبات المطوّر: ويندوز ٦٤ بت، Python 3.12 مع NumPy، و.NET SDK 8.0.425. لا يحتاج المستخدم تثبيت هذه المتطلبات؛ تتضمن الحزمة بيئات تشغيل محمولة. تعتمد الأداة على بيانات استخراج مملوكة للمستخدم في مجلدي `original/` و`remastered/`، وعلى ناتج بناء 2.0.1 الحالي في `apps/manager/data`.

```powershell
python build/tools/build_manual_release.py --original "D:/owned-extraction" --archives "D:/SteamLibrary/steamapps/common/KINGDOM HEARTS -HD 1.5+2.5 ReMIX-/Image/dt" --output "D:/new-manual-build"
```

يجب أن يكون مجلد الناتج جديدًا؛ لا تحذف الأداة ناتجًا سابقًا. يمكن تمرير `--openkh-zip` للأرشيف الرسمي المثبت `release2-1691`. يُتحقق من بصمته، وإلا يُنزّل تلقائيًا. يُنزّل Node 24.19.0 الرسمي وتُتحقق بصمة ZIP المثبتة. يثبّت المشروع إصدار runtime .NET 8.0.31. تبقى ملفات مصادر اللعبة للقراءة فقط.

بنية الفروق: بايتات الناتج XOR مقابل بايتات الأصل، مع تكرار الأصل دوريًا عند زيادة طول الناتج، ثم gzip ثابت بلا وقت إنشاء. يحتفظ الكتالوج بطول وبصمة كل أصل وناتج وفرق. لا يُقبل أصل فارغ، ولا يُقبل ناتج يتجاوز 128 ميجابايت للملف الواحد. لا يُرفق أصل كامل أو ملف ناتج كامل مشتق من اللعبة. تُولّد الملفات المطابقة محليًا قبل تمريرها إلى نسخة غير معدّلة من محرك 2.0.1.

يحتوي الناتج على ZIP وقائمة بصمات وتقرير بناء. تظهر نتائج التثبيت والحذف والتراجع والتحقق في تقرير اختبار منفصل. أوامر الاختبار:

```powershell
node manual/tests/package.cjs --package "D:/new-manual-build/KH2FM_AR_Manual" --game "D:/SteamLibrary/steamapps/common/KINGDOM HEARTS -HD 1.5+2.5 ReMIX-" --output "D:/new-test-workspace"
```

يقرأ الاختبار من اللعبة الحقيقية ويختبر الكتابة في مجلد تجريبي جديد فقط؛ لا يشغّل اللعبة. لا تُرفع مخرجات الاستخراج أو مجلد الاختبار أو cache إلى المستودع.
