# تعريب كينغدم هارتس ٢ — النسخة اليدوية 2.0.1

نفس تعريب وإصلاحات الإصدار 2.0.1، باسم توزيع مستقل **KH2FM_AR Manual Edition**. هذه نسخة بدون لانشر أو برنامج تثبيت رسومي؛ الإصدار العادي يبقى متاحًا والموصى به لمعظم المستخدمين، وقناة تحديثه تبقى كما هي.

1. حمّل `KH2FM_AR_Manual_v2.0.1.zip` وفكّه كاملًا.
2. أغلق KH2 وشغّل `Install_Arabic.bat`؛ يُكتشف مجلد ستيم أو يُطلب مساره.
3. بعد اكتمال التجهيز شغّل اللعبة من ستيم باللغة الإنجليزية.

تحتاج نسخة أصلية من اللعبة. الحزمة لويندوز ٦٤ بت ونسخة ستيم المختبرة، ولا تشمل PKG/HED أو ملفات اللعبة الأصلية الكاملة. تقرأ الأداة الأصول اللازمة من نسختك للقراءة فقط، ثم تولّد تعريبًا مطابقًا لـ2.0.1. أدوات التشغيل مرفقة ولا يلزم تثبيت Python أو Node أو .NET أو الاتصال بالإنترنت أثناء الاستخدام.

تتضمن ملفات للحذف والفحص والتراجع. تستخدم النسختان نفس سجل الملكية والنسخ الاحتياطية، مع فحص الملفات المتعارضة. ملفات الحفظ والملف التنفيذي وأرشيفات اللعبة لا تتغير. لا تشغّل أدوات التثبيت معًا، واحتفظ بمجلد `.kh2fm-arabic` للنسخ الاحتياطية.

التفاصيل والأخطاء والتراخيص داخل الحزمة. Epic ولينكس خارج نطاق هذه النسخة. جرى فحص توليد الملفات والتثبيت على مجلد تجريبي؛ المطابقة الآلية لا تعني اختبار كل شاشة بصريًا.
