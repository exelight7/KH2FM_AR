# تعريب Kingdom Hearts II Final Mix — 1.0.3

تعريب عربي مجاني لنسخة Steam، ببرنامج جديد للتثبيت وإدارة التعريب.

**الجديد:**

- واجهة عربية جديدة تضم الرسم الذي اختاره صاحب المشروع.
- اختيار مجلد اللعبة بنفسك.
- تثبيت التعريب وحذفه والتراجع من برنامج واحد.
- برامج لويندوز وماك ولينكس، مع نسخة احتياطية تلقائية قبل التغيير.
- تحسين الترقية من 1.0.1 و1.0.2، وحماية الملفات المعدّلة والمودات الأخرى.

**التثبيت:**

1. حمّل برنامج نظامك من **Assets** بالأسفل.
2. افتح البرنامج، ثم اختر مجلد اللعبة.
3. اضغط **تثبيت التعريب**، واختر **English** كلغة اللعبة في Steam.
4. شغّل اللعبة كالمعتاد. للحذف أو التراجع، افتح قائمة **•••** داخل البرنامج.

| النظام | الملف |
|---|---|
| Windows 10/11 | `KH2FM-Arabic-1.0.3-Windows-x64.exe` |
| macOS — Apple Silicon | `KH2FM-Arabic-1.0.3-macOS-arm64.dmg` |
| macOS — Intel | `KH2FM-Arabic-1.0.3-macOS-x64.dmg` |
| Linux — x64 | `KH2FM-Arabic-1.0.3-Linux-x64.AppImage` |
| Linux — ARM64 | `KH2FM-Arabic-1.0.3-Linux-arm64.AppImage` |

نسخة اللعبة على الكمبيوتر خاصة بويندوز. على لينكس يستخدم التعريب نسخة اللعبة عبر **Proton**، وعلى ماك عبر **Wine أو CrossOver**؛ تحتاج اللعبة أن تعمل عندك مسبقًا. تفاصيل التشغيل وملفات Linux البديلة موجودة في **README_AR.md**.

نصوص التعريب والخط والصور داخل اللعبة مطابقة لإصدار 1.0.2. هذا التحديث يركز على البرنامج والتثبيت وإدارة التعريب.
