# تعريب Kingdom Hearts II Final Mix — 1.0.3

تعريب عربي مجاني لنسخة Steam، ببرنامج جديد للتثبيت وإدارة التعريب.

**الجديد:**

- واجهة عربية جديدة تضم الرسم الذي اختاره صاحب المشروع.
- اختيار مجلد اللعبة بنفسك.
- تثبيت التعريب وحذفه والتراجع من برنامج واحد.
- برامج لويندوز وماك ولينكس، مع نسخة احتياطية تلقائية قبل التغيير.
- تحسين الترقية من 1.0.1 و1.0.2، وحماية الملفات المعدّلة والمودات الأخرى.

**التثبيت:**

1. حمّل برنامج نظامك من **Assets** بالأسفل.
2. افتح البرنامج، ثم اختر مجلد اللعبة.
3. اضغط **تثبيت التعريب**، واختر **English** كلغة اللعبة في Steam.
4. شغّل اللعبة كالمعتاد. للحذف أو التراجع، افتح قائمة **•••** داخل البرنامج.

| النظام | الملف |
|---|---|
| Windows 10/11 — أول ملف | `01-KH2FM-Arabic-1.0.3-Windows-x64.exe` |
| macOS — Apple Silicon | `02-KH2FM-Arabic-1.0.3-macOS-Apple-Silicon.dmg` |
| macOS — Intel | `03-KH2FM-Arabic-1.0.3-macOS-Intel.dmg` |
| Linux — x64 | `04-KH2FM-Arabic-1.0.3-Linux-x64.AppImage` |
| Linux — ARM64 | `05-KH2FM-Arabic-1.0.3-Linux-ARM64.AppImage` |

**الملفات الإضافية اختيارية:** `06-KH2FM-Arabic-1.0.3-Extras-and-Reports.zip` يجمع التقارير والصور والبصمات ونسخ ماك ولينكس البديلة. للتثبيت تحتاج برنامج نظامك فقط.

نسخة اللعبة على الكمبيوتر خاصة بويندوز. على لينكس يستخدم التعريب نسخة اللعبة عبر **Proton**، وعلى ماك عبر **Wine أو CrossOver**؛ تحتاج اللعبة أن تعمل عندك مسبقًا. تفاصيل التشغيل في **reports/README_AR.md** داخل ملف الإضافات.

نصوص التعريب والخط والصور داخل اللعبة مطابقة لإصدار 1.0.2. هذا التحديث يركز على البرنامج والتثبيت وإدارة التعريب.
