# متابعة تدقيق مصطلحات 1.0.7

نقطة الاستئناف: الإصدار `v1.0.7` عند الالتزام `718f0f1` منشور بالفعل، وفيه نهاية مراجعة اليوميات وملاحظات الإصدار. مجلد جلسة المراجعين `/tmp/claude-0/.../scratchpad/v107` لا يوجد في هذه البيئة؛ استعيدت النتائج المحفوظة من GitHub.

هذه متابعة على المصدر، وليست إعادة نشر أو استبدالا لملفات 1.0.7 المنشورة. لم يتغير برنامج التثبيت أو الخط أو دعم Windows x64 وLinux x64.

## التصحيحات

- 17 سطرا في اليوميات: «هذا الذروة» ← «هذه الذروة» و«سيلغى الذروة» ← «ستلغى الذروة».
- ثلاثة نصوص تعليمية: «الذروة قدرات» ← «قدرات الذروة».
- وصف الجني: «هجمات الذروة كثيرة» ← «هجمات ذروة كثيرة».

- وصف Auto Limit الخاص بشكل الذروة: إزالة «تلقائيةا» وتصحيح هدف أمر التفاعل إلى «على الذروة».
- وصف القناص في اليوميات `jm 12055`: «قنص التحول» ← «قنص الانتقال»، مطابقا لاسم الأمر `sys 8304`.

جميع التصحيحات عبر `corrections/` فقط؛ بقي `AR_old` مطابقا لنص المصدر، ولم يتكرر أي معرف. التفاصيل قبل/بعد في [1.0.7-terms.json](1.0.7-terms.json).
